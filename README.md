# Outlast Trials Stats Discord Bot

[![Invite Bot](https://img.shields.io/badge/Discord-Invite%20Bot-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.com/oauth2/authorize?client_id=1464019044817571941&scope=bot%20applications.commands&permissions=257698425936)

A Discord bot that automatically assigns roles, syncs nicknames, and displays leaderboards based on The Outlast Trials player stats from [outlasttrialsstats.com](https://outlasttrialsstats.com).

**[Add the bot to your server](https://discord.com/oauth2/authorize?client_id=1464019044817571941&scope=bot%20applications.commands&permissions=257698425936)**

## Features

- **Roles from stats:** assign roles by prestige, level, reagent rig skill, invasion ranking, invasion matches and points, platform, account type or a linked Outlast Trials Stats account
- **Auto-nicknames:** verified members get their in-game name as server nickname
- **Leaderboards:** view any stat category with `/leaderboard`, or post auto-updating leaderboards in a channel
- **Community events:** auto-updating progress message and role pings when a phase is reached or about to be reached
- **Languages and custom messages:** English or Deutsch, and every bot message can be overridden per server

See [docs/commands.md](docs/commands.md) for all commands.
